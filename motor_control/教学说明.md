# MuJoCo 单关节电机控制 —— 教学说明

> 项目位置：`motor_control/`　|　技术栈：MuJoCo + 纯 NumPy（无 PyTorch/GPU）
> 一句话概括：**用 PID 当老师生成数据 → 小神经网络模仿学习 → 可视化验证学生是否出师。**

---

## 一、这个项目在做什么

### 1.1 任务

在 MuJoCo 物理仿真里有一个绕 Z 轴旋转的臂（模拟直流电机驱动），
训练一个 3→32→32→1 的小 MLP（多层感知机）：

```
输入：当前角度 θ、角速度 ω、目标角度 target   （3 个数）
输出：该用多大的力矩（归一化到 -1 ~ 1）        （1 个数）
```

### 1.2 为什么要"模仿 PID"而不是直接用 PID

单关节场景 PID 确实更好（简单、精确、省算力）。这个项目的价值不在结果，
而在**跑通这条流水线**——它可以直接迁移到 PID 搞不定的场景：

| 场景 | 为什么 PID 不行 | 模仿/强化学习为什么行 |
|---|---|---|
| 多关节机械臂 | 6 个关节动力学耦合，18 个增益互相打架 | 网络一次前向输出全部关节力矩 |
| 肌肉/柔性驱动 | 非线性模型没有解析公式 | 不要求懂模型，只要数据 |
| Sim2Real 真实电机 | 摩擦、延迟、参数漂移难调 | 带噪声训练的网络天生鲁棒，且只有 ~1200 个参数，可烧进 STM32 |

### 1.3 学习范式：行为克隆（模仿学习）

```
┌─────────┐   控制仿真臂   ┌──────────────────┐
│ PID 老师 │ ────────────→ │ (θ, ω, target) → 力矩 │ × 40 万条
└─────────┘                └─────────────────┘
                                    │ 监督学习 (MSE)
                          ┌─────────▼─────────┐
                          │ MLP 学生（1200 参数）│
                          └───────────────────┘
```

**关键概念：模仿发生在训练阶段，不是运行时。**
训练完成后，学生和 PID 老师没有任何联系——运行时两者各自独立计算力矩。
它们动作一致，恰恰证明学生"把老师的本事背下来了"。

## 二、文件结构与运行顺序

```
motor_control/
├── motor.xml          # 单臂模型（训练数据生成用）
├── motor_dual.xml     # 双臂模型（对比演示用：蓝臂PID + 红臂MLP）
├── sim.py             # 仿真封装：reset / step / get_state
├── pid.py             # PID 老师
├── generate_data.py   # 第1步：PID 控制仿真臂，收集 40 万条状态→力矩样本
├── model.py           # MLP 定义（手写前向/反向传播，纯 NumPy）
├── train.py           # 第2步：监督学习模仿 PID
├── test_visual.py     # 第3步：MuJoCo 原生 viewer 可视化

```

运行：

```bash
py -3 generate_data.py    # 生成 data/motor_data.npz（约 40 万样本）
py -3 train.py            # 训练 300 epochs，loss 降到 0.001 以下
py -3 test_visual_cn.py   # 打开中文仪表盘看效果
```

## 三、核心概念逐条讲透

### 3.1 PID 三个增益在物理上干什么

被控对象：惯量 I≈0.08 kg·m²、阻尼 b=0.5、力矩上限 ±1 N·m 的旋转臂。

```
力矩 = kp×误差 + ki×误差积分 − kd×角速度
     = 20×(target−θ) + 0.1×∫误差 − 4×ω
```

| 项 | 物理直觉 | 调大的效果 | 调太大的副作用 |
|---|---|---|---|
| kp（比例） | 离目标越远越用力 | 响应快 | 冲过头（超调）、振荡 |
| kd（微分） | 测到速度就提前刹车 | 抑制超调 | 反应迟钝、放大噪声 |
| ki（积分） | 误差长期不为零就慢慢加力 | 消除稳态误差 | 积分饱和、振荡 |

**本项目调参实录**（文档原值 kp=5,ki=0.5,kd=1 是不能用的）：

- 原值下误差 1 rad 时 kp×误差=5，但力矩上限 1 → 86% 的时间输出饱和，
  PID 实际变成"全油门/全刹车"的 bang-bang 控制 → 持续振荡 → 学生学不会
- 改为 kp=20, ki=0.1, kd=4 后：饱和率 86%→6%，误差 <0.002，几乎不振荡
- **调参目标不只是"PID 自己稳"，而是给 MLP 造一个平滑、低饱和的老师**——
  映射越接近连续函数，网络越好拟合（阶跃函数很难用 tanh 输出逼近）

### 3.2 为什么输出层用 tanh

力矩限制在 ±1 N·m（`ctrlrange="-1 1"`），输出层 `tanh` 天然把网络输出
压在 (-1,1)，和物理约束一致，不需要额外裁剪。

### 3.3 "保持力矩"——不动 ≠ 不输出

臂停在目标位置时，控制器每毫秒仍在输出微小力矩维持位置（仪表盘上力矩
显示 -0.000 其实是约 -0.0004 N·m）。真实世界推论：

- 机械臂"站着不动"时电机持续耗电、可能发热（堵转特性）
- 断电 = 力矩消失 = 臂立刻掉下来，所以工业臂配抱闸
- 高精度定位 = 持续闭环微调，而不是"到位后锁死"

### 3.4 步进 vs 伺服（本项目）

| | 步进电机 | 伺服闭环（本项目） |
|---|---|---|
| 原理 | 开环：发 N 个脉冲走 N 步，不看反馈 | 闭环：实时读角度持续纠偏 |
| 丢步 | 负载突增会丢步且不自知 | 偏了立刻拉回 |
| 精度上限 | 步距角×细分 | **编码器分辨率**（控制器误差 ~0.001 rad 只是仿真值） |

实机精度瓶颈依次是：编码器位数 → 静摩擦死区 → 电流量化。

## 四、踩坑记录（真实调试过程，值得学习）

### 坑 1：`range="-3.14 3.14"` 被当成角度（致命）

MuJoCo 默认角度制！±3.14 **度** = ±0.055 弧度，臂刚动一点就被关节限位
弹回，表现为"臂卡在 0.055 不动"。
**修复**：`<compiler angle="radian"/>`。
**排查手法**：打印 `model.jnt_range` 对比 XML 写的值；观察 `qfrc_constraint`
出现 -23 N·m 的异常大力但 `ncon=0`（不是碰撞，是限位约束）。

### 坑 2：悬空臂与默认地面相交

geom 中心在 z=0 的胶囊，一半埋进自动生成的地面 → 摩擦卡住。
**修复**：加底座并把臂抬高到 z=0.1。

### 坑 3：PID 参数与执行器权限不匹配

见 3.1 节。教训：**先验证老师（PID 闭环收敛），再训练学生。**

### 坑 4：viewer 鼠标"拉不动"

`launch_passive` 循环没有 sleep，CPU 100% 占满，GLFW 事件队列饿死。
**修复**：按 `timestep` 做实时节流 `time.sleep(...)`。

### 坑 5：matplotlib 中文显示为方框

**修复**：`matplotlib.rcParams["font.sans-serif"] = ["Microsoft YaHei"]`。

## 五、对比仪表盘（test_visual_cn.py）玩法指南

界面：左上 3D 渲染（蓝臂=PID 老师、红臂=MLP 学生）、左下角度跟踪曲线、
右侧控制面板 + 实时状态表（含两臂角度差 Δθ）。

| 按钮 | 演示什么 |
|---|---|
| 启动/暂停 | 两臂独立运行，肉眼看几乎同步 |
| 改目标角度 | 两臂各自规划、节奏一致地转过去 |
| 施加扰动 | 两臂同时被踹飞（+0.8 rad 位移、-2 rad/s 初速），看各自恢复 |
| 只显示学生臂 | 藏起蓝臂，红臂照样工作 → 证明它不是"跟着"蓝臂动 |
| 重力：开 | 两臂各受 -0.3 N·m 持续下拉 |
| 负载：开 | 再叠加 -0.3 N·m |

### 重点实验：开重力+负载，看两个控制器的本质差异

| 控制器 | 稳态误差（实测） | 原因 |
|---|---|---|
| PID 蓝臂 | 0.017 → 持续收敛到 0 | 积分项不断累加直到误差消失 |
| MLP 红臂 | 0.047 停在偏差处 | **训练数据里没有重力**，它只会复刻"零重力下的老师" |

**这是模仿学习的天花板：能力上限 = 训练数据的覆盖面。**
环境一变化（重力/负载/摩擦），学生立刻露馅。

### 怎么让学生也学会抗重力

改 `generate_data.py`：随机扰动重力力矩再采集数据——

```python
# episode 开始时随机采样一个常值扰动，让 PID 去对抗它
disturbance = np.random.uniform(-0.6, 0.6)
sim.data.qfrc_applied[0] = disturbance
```

这样 X 里出现"带偏差的稳态"，Y 里出现"抵消重力的非零力矩"，
学生就能学到重力补偿。**这一步就是 Sim2Real 的核心功课。**

## 七、下一步学习路线

按难度递增（对应原文档"进阶方向"）：

1. **带扰动重训**：把重力/摩擦/噪声加进 `generate_data.py`，看红臂也能消差（第一节实验的自然延续）
2. **多关节**：2-3 个 hinge 串联成平面机械臂，输入输出维度同时扩展，MLP 结构不用改——体会"网络不关心关节数，PID 会疯"
3. **强化学习**：去掉 PID 老师，用 PPO 让网络自己试错。模仿学习是"有标准答案"，RL 是"没有答案只有分数"
4. **Sim2Real**：`model_motor.npz` 的 1200 个参数转成 C 数组烧进 STM32 + 编码器 + 驱动板，控制真实舵机——你最初的目标（微电机/肌肉/机械臂）就在这条路上
