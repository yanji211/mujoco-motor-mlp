# MuJoCo 单关节电机控制 —— 小 MLP 模仿 PID

用 MuJoCo 物理仿真 + 纯 NumPy 手写神经网络，完成一个完整的**行为克隆（模仿学习）**入门项目：
PID 老师控制单关节电机臂 → 采集 40 万条状态-力矩数据 → 3×32×32×1 小网络（约 1200 参数）
监督学习老师的控制手艺 → 中文仪表盘实时对比双臂 + 混合控制（MLP 前馈 + PID 兜底）。

## 效果

- 训练 loss（MSE）= **0.0009**，5 个目标角度稳态误差 < 0.0015 rad
- 50 组随机初始状态（含 ±1 rad/s 初速冲击）鲁棒性测试 **0 失败**
- 混合模式：开重力扰动后，纯 MLP 稳态误差 0.020 → 混合控制 **0.005~0.008**

## 快速开始

```bash
pip install mujoco numpy matplotlib pillow

cd motor_control
py -3 generate_data.py     # ① 生成数据（约 1 分钟，data/motor_data.npz）
py -3 train.py             # ② 训练（输出 model_motor.npz）
py -3 test_visual_cn.py    # ③ 打开中文对比仪表盘
```

## 仪表盘玩法

| 按钮 | 演示内容 |
|---|---|
| 启动 / 复位 | 双臂从 0 转到目标角度，看跟踪曲线 |
| 施加扰动 | 两臂同时被"踹飞"，看独立恢复（证明不是运行时跟随） |
| 只显示学生臂 | 藏起蓝臂，红臂照样工作——模仿发生在**训练阶段** |
| 重力 / 负载 | 加 -0.3 N·m 常值扰动：纯 MLP 留稳态误差，PID 靠积分清零 |
| 红臂：纯 MLP（切混合） | 切换 τ = 0.7·MLP前馈 + 小增益PID兜底，看误差被兜底项消掉 |
| 鼠标左键拖拽 / 滚轮 | 旋转视角 / 缩放 |

## 核心概念速览

- **模仿学习**：网络学的不是"跟着蓝臂动"，而是训练时背下 40 万条 `(θ, ω, θ_ref) → τ` 映射；
  运行时两臂各自独立计算，动作一致恰好证明学成了（Δθ 微小波动 = 两个独立大脑）。
- **保持力矩**：臂"不动"时控制器仍在输出微小力矩维持位置——断电即瘫、堵转发热，
  这是伺服（闭环+反馈+力矩可控）与步进（开环走脉冲）的本质分界。
- **为什么 kp=20 而不是 5**：原值在 ±1 力矩限幅下 86% 样本饱和成 bang-bang 振荡，
  老师自己都收敛不了；重调后饱和率 6%，映射平滑，学生才学得会。
- **混合架构（hybrid.py）**：MLP 出力矩大头（快、平滑），小增益 PID 兜残差（消重力稳态误差），
  前馈发散 10 拍自动屏蔽降级纯 PID——神经网络坏了机器不停，这是工业落地的前提。

## 进阶路线

1. 数据里加观测噪声 / 摩擦模型 → 重训看鲁棒性
2. 多关节（3 DOF 平面臂）→ 网络输入 6+3 维
3. 换 PPO 强化学习从头学（不再依赖 PID 老师）
4. `hybrid.export_c_header()` 导出权重 → 烧 STM32 驱动真实伺服（Sim2Real）
